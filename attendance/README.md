# 일일 근태현황

공용 엑셀로 하던 **회전기사업본부 일일 근태현황**을 웹으로 옮긴 도구입니다.

- **구글 계정 없이** 이름 + PIN 번호(숫자 4~8자리)로 로그인합니다.
- 관리자가 만든 계정만 들어올 수 있습니다. 링크만 알아서는 아무것도 볼 수 없습니다.
- 휴대폰·PC 모두 됩니다. 글씨와 버튼을 크게 만들었습니다.
- AI를 쓰지 않습니다. 사용료도 들지 않습니다.

```
attendance/
├─ index.html             화면 (디자인)
├─ app.js                 화면 동작
├─ config.js              ★ 서버 주소 넣는 곳
├─ core.js                서버 로직 (로그인·권한·저장 규칙)
├─ local-backend.js       체험 모드용 (서버 주소가 비어 있을 때)
├─ apps-script/Code.gs    ★ 구글 시트에 붙여 넣는 서버 코드 (core.js + sheets-env.js를 합친 것)
├─ apps-script/sheets-env.js
├─ tools/build-gs.sh      core.js를 고친 뒤 Code.gs를 다시 만드는 스크립트
└─ vendor/                엑셀 파일 만들기 (SheetJS)
```

## 할 수 있는 것

| 기능 | 설명 |
|---|---|
| 일일 현황 | 부서별 총인원·근무자·출장·본사근무·교육·휴가, 사내협력사 인원, 기타(공장내 작업). 날짜를 앞뒤로 넘겨 지난 날도 봅니다 |
| 입력 | 부서를 누르면 이름(+행선지/메모)을 넣는 창이 뜹니다. 근무자 수는 자동 계산 (총인원 − 출장 − 교육 − 휴가, **본사근무는 근무로 셈**) |
| 전날 내용 불러오기 | 며칠씩 가는 출장은 전날 것을 불러와 그대로 저장 |
| 남은 부서 이상 없음 | 아직 입력 안 된 내 담당 부서를 한 번에 "빠진 사람 없음"으로 저장 |
| 입력 현황 | 부서마다 입력/미입력, 누가 몇 시에 입력했는지 표시 |
| 인쇄 | A4 가로, 기존 엑셀 양식처럼 나옵니다 |
| 엑셀 받기 | 그날 현황을 .xlsx로 저장 |
| 기간 통계 | 기간을 골라 부서별 출근율, 일자별 추이, 사람별 출장·교육·휴가 일수 (엑셀로도 받기) |
| 관리 | 계정(권한·담당 부서·PIN 재설정·사용 중지), 부서/협력사 추가·순서·기본 인원, 설정, 기록(누가 언제 무엇을 바꿨는지) |

### 권한

| 권한 | 볼 수 있는 것 | 입력할 수 있는 것 |
|---|---|---|
| 관리자 | 전부 | 전부 + 계정·부서·설정 관리 + 오래된 날짜 수정 |
| 입력 담당 | 전부 | 관리자가 체크해 준 부서·협력사·기타 칸만, 최근 N일(기본 7일)까지 |
| 조회 전용 | 전부 | 없음 |

예) 생산관리Part 담당자 → 입력 담당 + "생산관리Part" + "사내협력사 전체" 체크.

### 보안

- PIN은 시트에 그대로 저장하지 않고 암호화(해시)해서 저장합니다. 관리자도 남의 PIN을 볼 수 없고 새로 정해 줄 수만 있습니다.
- PIN을 5번 틀리면 그 이름은 10분 동안 로그인할 수 없습니다.
- 로그인은 12시간 유지됩니다 ("이 기기에서 로그인 유지"를 체크하면 30일).
- PIN을 바꾸거나 계정을 "사용 안 함"으로 하면 그 사람의 기존 로그인은 바로 풀립니다.
- 데이터는 관리자 구글 드라이브의 시트 하나에만 있습니다. 시트는 **공유하지 마세요** (관리자 본인만).

## 먼저 체험해 보기

`config.js`의 `apiUrl`이 비어 있으면 **체험 모드**로 열립니다 (이 브라우저에만 저장).
처음 로그인: 이름 **관리자** / PIN **1234** → 바로 새 PIN을 정하게 됩니다.

GitHub Pages가 켜져 있으면 `https://bravado0.github.io/-/attendance/` 에서 열립니다.
내 PC에서 볼 때: `cd attendance && python3 -m http.server 8000` → http://localhost:8000

## 실제 운영 설정 (10분, 한 번만)

구글 계정은 **관리자 한 사람만** 있으면 됩니다. 다른 직원들은 구글 계정이 필요 없습니다.

1. 관리자 구글 계정으로 https://sheets.new 에서 새 스프레드시트를 만들고 이름을 `근태현황 DB`로 바꿉니다.
2. 메뉴 **확장 프로그램 → Apps Script** 를 엽니다.
3. 원래 있던 `Code.gs` 내용을 모두 지우고, 이 저장소의 **`attendance/apps-script/Code.gs`** 내용을 통째로 붙여 넣고 저장(💾)합니다.
4. 위쪽 함수 선택 칸에서 **`setup`** 을 고르고 **실행**을 누릅니다.
   - 처음에는 "권한 검토" 창이 뜹니다 → 내 계정 선택 → "고급" → "(안전하지 않음)으로 이동" → 허용.
     (본인이 만든 스크립트라서 뜨는 안내입니다.)
   - 시트에 `부서`, `협력사`, `계정`, `부서일일` … 탭이 생기고 지금 엑셀의 부서·협력사가 들어갑니다.
5. 오른쪽 위 **배포 → 새 배포** → 톱니바퀴에서 **웹 앱** 선택
   - 실행 계정: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자** (← 그래야 구글 계정 없는 사람도 씁니다. 로그인은 앱의 PIN이 막습니다)
   - **배포** → 나온 **웹 앱 URL** (`https://script.google.com/macros/s/…/exec`)을 복사합니다.
6. 이 저장소의 `attendance/config.js` 에 붙여 넣고 커밋합니다.
   ```js
   window.ATTENDANCE_CONFIG = {
     apiUrl: 'https://script.google.com/macros/s/…/exec'
   };
   ```
7. 앱을 열고 **관리자 / 1234** 로 로그인 → 새 PIN을 정한 뒤 **관리 → 계정**에서 직원 계정을 만들고 PIN을 알려 줍니다.

### 나중에 서버 코드를 고쳤을 때

`core.js`나 `apps-script/sheets-env.js`를 고쳤다면 `./tools/build-gs.sh`로 `Code.gs`를 다시 만들고,
Apps Script에 다시 붙여 넣은 뒤 **배포 → 배포 관리 → 편집(연필) → 버전: 새 버전 → 배포**를 누릅니다.
(이렇게 하면 주소가 바뀌지 않습니다. "새 배포"를 하면 주소가 바뀌니 주의.)

### 관리자 PIN을 잊었을 때

Apps Script 편집기에서 함수 **`resetAdminPin`** 을 실행하면 관리자 PIN이 `1234`로 돌아갑니다 (로그인 후 바로 바꾸게 됨).

## 자주 묻는 것

- **직원이 PIN을 잊었어요** → 관리 → 계정 → 수정 → "PIN 새로 정하기"에 새 번호를 넣고 저장.
- **퇴사·전배** → 계정 "사용" 체크 해제. 입력 기록은 남습니다.
- **부서 인원이 바뀌었어요** → 관리 → 부서 → 기본 총인원 수정. (그날 인원만 다르면 입력 창에서 총인원을 바꾸면 됩니다.)
- **데이터 백업** → 구글 시트이므로 파일 → 다운로드 → Excel로 언제든 받을 수 있습니다. 시트는 직접 고치지 말고 앱에서 고쳐 주세요.
- **비용** → 무료 (Google Apps Script 무료 한도 안에서 충분합니다).
- **응답 속도** → 구글 서버를 거치므로 저장에 1~2초 걸릴 수 있습니다.
