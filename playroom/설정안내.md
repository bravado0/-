# 🌈 우리 놀이방 - 설정 안내

둘이 동시에 접속해서 **같이 그림 그리고 공놀이**하는 실시간 2인용 게임입니다.
아이들은 로그인 없이 링크만 누르면 되고, 홈 화면에 아이콘으로 추가할 수 있어요.

실시간으로 연결하려면 **아빠(부모)가 딱 한 번** 무료 Firebase 서버를 만들면 됩니다.

---

## 1단계. Firebase 프로젝트 만들기 (약 5~10분, 무료)

1. https://console.firebase.google.com 접속 → 구글 로그인
2. **프로젝트 추가** → 이름 아무거나(예: `우리놀이방`) → 만들기
   (Google 애널리틱스는 꺼도 됩니다)
3. 왼쪽 메뉴에서 **빌드 → Realtime Database** 선택
   - **데이터베이스 만들기** 클릭
   - 위치: `asia-southeast1` 등 아무거나
   - 보안 규칙: **"테스트 모드로 시작"** 선택 → 사용 설정
4. 왼쪽 위 ⚙️ **프로젝트 설정** → 아래로 내려 **내 앱** → **웹(</>)** 아이콘 클릭
   - 앱 닉네임 입력(아무거나) → 등록
   - 화면에 나오는 `firebaseConfig = { ... }` 코드가 보입니다. **이걸 복사**하세요.

## 2단계. 설정값 넣기

복사한 `firebaseConfig` 내용을 저(클로드)에게 그대로 붙여넣어 주세요.
제가 `playroom/index.html` 안에 넣어드립니다.

> 참고: 이 설정값은 비밀번호가 아니라서 공유해도 괜찮습니다.

## 3단계. 배포 (링크 만들기)

설정값을 넣으면 공개 링크를 만들어드립니다. (GitHub Pages 또는 Firebase 호스팅 — 둘 다 무료)
그 링크를 두 따님 폰에서 열면 끝!

## 4단계. 폰에 앱처럼 추가하기

- **아이폰(사파리)**: 링크 열기 → 공유 버튼 → **"홈 화면에 추가"**
- **안드로이드(크롬)**: 링크 열기 → 오른쪽 위 ⋮ → **"홈 화면에 추가"**

이제 홈 화면 아이콘을 누르면 전체화면 게임이 열립니다.

---

## 놀이 방법
- **이름**과 **캐릭터**를 고르고, **방 이름은 둘이 똑같이**(예: `우리집`) 입력 → 입장
- 아래 버튼으로 모드 전환:
  - 🕹️ **이동**: 손가락 따라 내 캐릭터가 움직여요
  - 🎨 **그림**: 둘이 같이 그려요 (색 선택 / 전체지우기)
  - ⚽ **공**: 공을 잡아서 휙 던지면 상대가 받아요
- 진행 중 화면은 서로 실시간으로 똑같이 보입니다.

## 안전 메모
"테스트 모드"는 30일 뒤 잠깁니다. 계속 쓰려면 규칙을 아래처럼 바꾸면 돼요
(가족끼리 쓰는 간단한 게임용):

```json
{
  "rules": {
    ".read": true,
    ".write": true
  }
}
```
방 이름을 남이 모르게만 하면 가족용으로 충분합니다.
(더 안전하게 잠그고 싶으면 알려주세요.)
