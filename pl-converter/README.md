# 손익 양식 변환기

프로젝트 원가 RAW 파일(`FF○○○○○(프로젝트).xlsx`)을 손익 양식 엑셀(`FF○○○○○.xlsx`)로 바꿔 주는 HTML 파일 한 개짜리 도구입니다.
인터넷 없이 더블클릭으로 열리고, 파일은 PC 밖으로 나가지 않습니다.

## 쓰는 법
1. `손익양식변환기.html`을 더블클릭해 엽니다(크롬·엣지).
2. 프로젝트 원가 파일을 끌어다 놓습니다. 여러 개를 한 번에 넣어도 됩니다.
   - 선택: `계정별 원장(○월).xlsx`를 넣으면 매출액 실적이 채워집니다.
   - 선택: `FF○○○○○(재공품).xlsx`를 넣으면 아래쪽 재공품 원가 비교표가 채워집니다(파일 이름의 프로젝트 번호로 짝을 찾습니다).
3. **변환하기**를 누르면 파일이 받아집니다. 여러 개일 때는 **전체 한 번에 받기(zip)**를 쓰면 됩니다.

화면에는 요약표와 검증 결과(자재비·매출원가가 원본 합계와 맞는지)가 나옵니다. 양식에 줄이 없는 원본 항목도 함께 보여 줍니다.

## 기존 수식 방식과 다른 점
- 원본의 행 위치가 프로젝트마다 달라도 구간(원자재비, 구입자재비, 부자재비, 노무비 …)을 스스로 찾습니다. 그래서 위쪽 `MATCH` 보조 칸과 "수정해" 표시는 없앴습니다.
- 부자재비는 원본에 같은 이름으로 두 줄(제목, 항목) 있어서 기존 수식이 두 번 더하던 것을 한 번만 더하도록 고쳤습니다.
- `Inlet Damper` 줄에 `Outlet Damper`를 더하는 규칙은 계획에만 있었는데, 실적에도 똑같이 적용했습니다.
- 외부 파일 연결은 모두 없앴고 값으로 채웁니다. 합계·차이·검증 수식은 그대로 남아 있어서 엑셀에서 열면 다시 계산됩니다.

## 만들기(개발용)
양식은 회사 자료이므로 저장소에 넣지 않습니다. 완성본 양식 파일로 직접 빌드합니다.

```
python3 build.py <완성본 양식.xlsx>        # → dist/손익양식변환기.html
node verify.js <원본(프로젝트).xlsx> [계정별 원장.xlsx|-] [재공품.xlsx|-] [출력.xlsx]
```

`build.py`는 완성본에 들어 있는 외부 참조 수식을 읽어 "어느 칸에 무엇을 채울지"를 뽑습니다. 양식 줄을 추가하거나 바꾼 뒤 다시 빌드하면 그대로 반영됩니다.

## 엑셀 매크로 버전 (`macro/PLConverter.bas`)
회사 PC에서 HTML을 쓸 수 없을 때 쓰는 방법입니다. 규칙은 HTML 버전과 같습니다.

1. 새 엑셀 통합문서를 **매크로 사용 통합 문서(.xlsm)**로 저장합니다(예: `손익변환기.xlsm`).
2. `Alt+F11` → 삽입 → 모듈 → `PLConverter.bas` 내용을 붙여넣습니다(또는 파일 → 파일 가져오기).
3. `Alt+F8` → `ConvertPL` 실행
   1) 양식 파일: **외부 연결 수식이 들어 있는 원래 완성본**. 처음 한 번만 고르면 기억합니다.
   2) 프로젝트 원가 파일: 여러 개 선택 가능
   3) 계정별 원장: 없으면 취소
   - 재공품 파일은 원본과 같은 폴더의 `FF○○○○○(재공품).xlsx`를 알아서 찾습니다.
4. 결과는 원본 폴더 아래 `변환결과\FF○○○○○.xlsx`로 저장되고, 끝나면 검증 결과가 나옵니다.

> 결과 파일은 외부 연결 수식이 값으로 바뀌어 있으므로 다음 달 양식으로 쓰면 안 됩니다. 원래 양식은 따로 보관하세요.
